# Ελληνικά — мои слова

Греческо-русский словарь и тренажёр с карточками, тестами и произношением.

[Открыть приложение](https://anton-romanov.github.io/greek-vocabulary/)

Словарь встроен в `index.html`. Прогресс и правки сохраняются в браузере. Чтобы перенести их на другое устройство, воспользуйтесь экспортом и импортом в приложении.
